# Clarity source and attribution

This is the owner-authorized relocation of Daniel Gruss's Clarity theme from
USCE into its Themes package. The theme definition, Blue skin and six small PNG
panel/progress textures are copied byte-for-byte; no new external media is added.

- Original author/date: Daniel Gruss, May 20, 2026.
- Original source: [USCE commit 0203e0363285c2dc177725ca24e91396a7a83545](https://github.com/UltraStar-CE/USCE/commit/0203e0363285c2dc177725ca24e91396a7a83545).
- Imported game-branch commit: [2afb421875818fe2a5d9b7d1e50e4e430f408319](https://github.com/UltraStar-CE/USCE/commit/2afb421875818fe2a5d9b7d1e50e4e430f408319).
- Imported paths: `game/themes/Clarity.ini` and `game/themes/Clarity/*`, now at
  the Themes repository root. Git import preserves the original author/date.
- The source project's [GPL-2.0 license](https://github.com/UltraStar-CE/USCE/blob/2afb421875818fe2a5d9b7d1e50e4e430f408319/LICENSE)
  and existing creator attribution are retained; relocation does not relicense
  upstream artwork.

Clarity inherits Modern rather than duplicating its media. The original
`Creator = Ultrastar Deluxe Team` credit remains in the theme definition.
Inherited Modern assets remain governed by their existing source notices.
