# Halloween

Select Modern as the theme and Halloween as the skin in Options > Themes.
Orange is the skin's default color. The menu background and six default avatars
use new artwork generated for USCE with OpenAI image generation on 2026-10-28.
The background includes a subtle translucent USCE wordmark.

Inspired by SimonDaniel21's Halloween-party skin, discussed in
[Themes #18](https://github.com/UltraStar-CE/Themes/issues/18).
No artwork from that skin is included. Modern supplies the remaining textures
and layouts, including its generic player layouts and aspect-ratio scaling.
