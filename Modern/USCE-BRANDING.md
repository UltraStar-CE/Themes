# USCE backgrounds

The season-specific backgrounds and revised loading PNGs were introduced on
2026-11-22. Blue's widescreen song background also uses the new artwork.
[Source and build instructions](https://github.com/UltraStar-CE/Themes/blob/main/.github/artwork-source/README.md)
record the artwork and wordmark origin.

Themes [#44](https://github.com/UltraStar-CE/Themes/pull/44) restored the
previous `[bg-main]blue.jpg` after that replacement. The restored file is a
blue gradient with the [USCE wordmark](https://github.com/UltraStar-CE/USCE/blob/a2072d52bfc5d7a006e14d10bcc94ab1bc8b1008/branding/usce-logo-horizontal.png).

The 2026-10-16 menu adaptations are documented in
[their original commit](https://github.com/UltraStar-CE/Themes/commit/63af239).
The 2026-10-19 edits to inherited loading photos are documented in the
[loading-screen change](https://github.com/UltraStar-CE/Themes/commit/5cd309f).
The original theme creator credits and existing notices remain in place.
